## 6. What the product now claims

The change is made, each requirement is checked by evidence the coding model did not write, and
the report says what is complete and what is uncertain. Concretely: R1, the task as the user wrote
it, is satisfied only where a decisive witness is one the coding model did not choose (a test
written from the wording by a separate call that never saw the change, a base test the change makes
pass, a claim or version constraint read from the wording, or the user's own held-out checks);
where every witness is the model's own, the report says `self-attested` and the run is
`incomplete: independent evidence missing`. The harness, not the model, runs the checks after each
change and decides when to verify. Whether this closes the plan is Brad's call.
