# Support

**Bugs and confusing setup**: open an issue on
[moonrunnerkc/swarm-orchestrator](https://github.com/moonrunnerkc/swarm-orchestrator/issues).
Both `swarm` and `swarm-verify` are supported there. A minimal reproduction and the version
make the difference between a question and a fix.

**Security**: privately, through [SECURITY.md](SECURITY.md).

**Who answers**: the maintainer, Brad Kinnard (`@moonrunnerkc`), aiming for a first response
within a few days. A fix for a reproducible defect ships as a compatible release, with the
version named on the issue.
