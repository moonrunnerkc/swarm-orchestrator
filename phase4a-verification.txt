### Smoke-finding-1 (ORCHESTRATOR BUG): main/master branch assumption
  The orchestrator bailed with stderr 'Error: Failed to switch to branch main'.
  sympy/sympy's default branch is 'master', not 'main'. The orchestrator's
  branch manager assumes 'main' exists and errors when it doesn't. This will
  break on ALL older OSS repos (sympy, scikit-learn pre-2022, etc.).
  Impact on the sweep: 23/50 instances are django (main), 27/50 are likely
  master-default repos. Without a fix, ~half the sweep is a pre-verified
  null outcome.

### Smoke-finding-2 (HARNESS ENV MISMATCH): Python 3.12 vs old-sympy
  Test collection errored with "ImportError: cannot import name 'Mapping'
  from 'collections'". sympy@c807dfe (2017) uses the pre-3.10 collections
  import path that was removed in 3.10. The eval container runs Python 3.12.
  Impact: older snapshots need per-instance Python version selection.
  SWE-bench's own harness handles this via per-instance docker images;
  our benchmarks/swe-bench/Dockerfile.eval does not. A sweep using our
  current harness will false-negative on old-snapshot instances.

### Smoke-finding-3 (HARNESS TEST ISOLATION): conftest double-registration
  pytest hit "ValueError: option names {'--slow'} already added" because
  BOTH the repo's conftest.py AND the conftest.py in the swarm worktree
  subdirectory get collected. Pytest's default rootdir discovery isn't
  scoped to the repo's own tests.

## Recommendation to Brad (for the next-sweep decision)
  Before authorizing the 50-instance sweep:
  (a) Fix the main/master branch assumption in the orchestrator (one-line
      change to detect default branch via 'git symbolic-ref refs/remotes/
      origin/HEAD'). Without this, ~27/50 instances pre-fail.
  (b) Decide on Python version strategy: adopt SWE-bench's official
      per-instance Docker images, or restrict the 50 to instances whose
      base commits are Python 3.11+ compatible.
  (c) Fix the pytest conftest double-registration by invoking pytest with
      an explicit --rootdir pointing at the repo, not the worktree parent.
  After (a)-(c), run a 3-instance smoke (1 django, 1 sympy, 1 matplotlib)
  to get real per-task cost numbers. That number drives the sweep budget.
